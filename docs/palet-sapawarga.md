# Palet Integral terinspirasi Sapawarga

Referensi yang dibaca: https://jabarprov.go.id/sapawarga pada 17 November 2026. CSS publik halaman menggunakan green-600 #16a75c, green-700 #069550, green-800 #008444, mint #e6f6ec, border mint #c3e9d0, dan green-300 #70cd94.

Integral menggunakan #008444 untuk tombol utama agar teks putih lebih terbaca, #16a75c untuk aksen, mint untuk label dan panel informasi, serta latar netral kehijauan. Sidebar menggunakan hijau tua #005c36, hover mint #e6f6ec dan menu aktif mint #c3e9d0. Aksen navy/biru sebelumnya dihapus sesuai revisi pengguna. Banner utama menggabungkan gradasi hijau tua; status peringatan/bahaya mempertahankan warna semantiknya.

Berkas: public/assets/css/integral-brand.css dimuat setelah tema dan sidebar, sedangkan public/assets/js/config.js memberi warna default grafik. Preferensi Light/Dark tetap menggunakan integral:appearance. Mode gelap memakai canvas #0f1b1b, surface #182b2a, mint terang sebagai teks aksen dan panel gelap tanpa blok putih. CSS palet hanya berlaku pada media screen; format cetak/PDF tidak berubah.

Verifikasi: render halaman Kelola Pelatihan dan dashboard evaluasi; pemeriksaan Chrome pada desktop dan viewport 390 piksel, penyimpanan/reload pilihan tema, kontrol tetap berada dalam viewport dan tanpa overflow horizontal. Sumber referensi disimpan privat sebagai bahan inspeksi; tidak menjadi dependensi runtime aplikasi.
