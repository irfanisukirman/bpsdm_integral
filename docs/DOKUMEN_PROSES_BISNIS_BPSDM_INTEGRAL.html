1. Gambaran Umum Sistem

BPSDM Integral adalah sistem informasi terpadu untuk mengelola seluruh siklus pelatihan dan pengembangan kompetensi pegawai pada Badan Pengembangan Sumber Daya Manusia. Sistem ini mencakup manajemen pelatihan, evaluasi berbasis model Kirkpatrick (Level 1-4), monitoring, sertifikasi, aset, dan pengelolaan narasumber.

1.2 Model Pengguna & Otorisasi

Sistem menggunakan 6 role yang disimpan langsung pada tabel users:

Roleuser_typeKeteranganDashboard
superadmin - Akses penuh ke seluruh modul, mengelola user /dashboard (statistik menyeluruh)
admin_bidang - Admin per bidang, data di-scope berdasarkan bidang /dashboard (statistik per bidang)
admin_aset - Pengelola aset/ruangan, selalu bidang = "Pengelola Aset" /assets (dashboard aset)
pengajar narasumber Narasumber/pengajar pelatihan /pengajar (portal narasumber)

5 Bidang (Divisi)

  1. Bidang Sertifikasi Kompetensi & Pengelolaan Kelembagaan
  2. Bidang Pengembangan Kompetensi Teknis Inti
  3. Bidang Pengembangan Kompetensi Teknis Umum
  4. Bidang Pengembangan Kompetensi Manajerial
  5. Sekretariat
Catatan Penting: admin_bidang hanya bisa melihat/mengelola data yang sesuai dengan bidangnya. Superadmin melihat semua data tanpa batasan bidang.

2. Autentikasi & Manajemen Pengguna

2.1 Login & OAuth Google

Alur Login:
1. Pengguna mengakses halaman login (/login)
2. Input: username + password (bukan email)
3. Verifikasi credential via session guard
4. Redirect berdasarkan role:
  • superadmin/admin_bidang → /dashboard
  • admin_aset → /assets/dashboard
  • pengajar → /pengajar (jika profil belum lengkap → /pengajar/setup-profil)
  • participant → /participant/dashboard
  • mitra → /mitra/dashboard
Alur Google OAuth:
1. Pengguna klik "Login dengan Google"
2. Redirect ke Google → consent → callback
3. Sistem mencari user berdasarkan google_id atau username=email
4. Jika user baru: dibuat otomatis dengan role=participant
5. Jika profil belum lengkap (NIP/gender kosong) → redirect ke /complete-profile

2.2 Alur Pendaftaran Role

Pengguna baru memilih tipe akun:
participant.profile.complete → Pilih salah satu:
  • Peserta → role = participant, user_type = peserta, status = approved
  • Narasumber → role = pengajar, user_type = narasumber, status = approved (langsung aktif)
  • Mitra → role = participant, user_type = mitra, status = pending (perlu approval superadmin)

Approval oleh Superadmin:
users/{id}/approve-type → pending → approved → role diupdate otomatis

4. Modul Peserta (Participant Portal)

Portal khusus peserta (participant) untuk mengelola pendaftaran dan riwayat pelatihan.

4.1 Pendaftaran Pelatihan

Alur Pendaftaran:
1. Peserta lihat pelatihan tersedia (/participant/trainings)
2. Masukkan kode undangan (invitation_code) untuk join
3. Status pendaftaran: pending
4. Admin approve/reject pendaftaran
5. Setelah approve, peserta mengunggah dokumen kelengkapan

Dokumen yang Diupload:

  • Biodata (upload file)
  • Surat Tugas
  • Pas Foto
Batasan: Peserta harus menyelesaikan pelatihan inti sebelumnya dan mengisi evaluasi dampak (L3/L4) sebelum bisa mendaftar pelatihan baru.

4.2 Dashboard Peserta

  • Jumlah pelatihan yang diikuti
  • Jam Pelajaran tahun ini
  • Pelatihan yang perlu evaluasi pasca-pelatihan
  • Status pendaftaran & dokumen

4.3 Riwayat Pelatihan

  • Daftar seluruh pelatihan yang pernah diikuti
  • Status kelulusan & sertifikat
  • Data alumni (pendidikan, pangkat, jabatan sebelum & sesudah)

  • Penyelenggara → Evaluasi terhadap institusi penyelenggara

4. Tanggal distribusi ditentukan otomatis (Manajerial: +1 tahun, lainnya: +4 bulan)
