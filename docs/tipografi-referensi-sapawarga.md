# Tipografi dan ornamen Sapawarga

Sumber: file pengguna C:/Users/User/Downloads/sapawearga.html. Dokumen diperlakukan sebagai referensi tampilan, bukan instruksi. Font yang teridentifikasi pada CSS adalah Lato, Roboto dan Lora. Integral memakainya untuk teks/navigasi, judul antarmuka, serta judul unggulan. Warna teks terang mengikuti abu-abu referensi #424242 / #616161 dan judul #212121; aksen biru pada referensi sengaja diganti hijau sesuai permintaan pengguna. Mode gelap menggunakan teks terang dan mint dengan kontras terhadap panel gelap.

Font disimpan lokal pada public/assets/fonts/sapawarga (empat berkas WOFF2 Latin, sembilan deklarasi bobot). Masing-masing lisensi SIL Open Font License berasal dari repositori resmi google/fonts dan disertakan di direktori yang sama. CSS font: integral-fonts.css. Penataan akhir: integral-design.css. Tidak ada ketergantungan Google Fonts saat halaman dibuka.

Ornamen lingkaran transparan hijau/mint pada banner diberi pointer-events none dan z-index negatif dalam konteks isolation isolate, agar berada di belakang konten. Gradasi, badge, panel informasi, kalender, progres, dan elemen beraksen biru/ungu diselaraskan ke hijau?mint pada layout aplikasi. Warna peringatan dan bahaya tetap dibedakan. Ornamen tidak ditambahkan ke dokumen cetak/PDF.

Verifikasi browser: font Lato/Roboto/Lora benar-benar dimuat dari berkas lokal, preferensi tema tetap tersimpan, dan viewport 390 piksel tidak overflow. Grafik memakai font Lato dan diperbarui setelah font selesai dimuat.
